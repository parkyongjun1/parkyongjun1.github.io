## **Code**
```python
def solution(routes):
    answer = 0
    routes.sort(key = lambda x: x[1])
    
    check_line = -300001
    cnt = 0
    for route in routes:
            if route[1] > check_line and route[0] > check_line:
                cnt += 1
                check_line = route[1]+0.5
    return cnt
```
